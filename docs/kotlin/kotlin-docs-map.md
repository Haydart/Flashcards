    - **[Kotlin Symbol Processing API](https://kotlinlang.org/docs/ksp-overview.html)** — A source code generation framework enabling processors to generate code based on annotations, used for dependency injection, serialization, and database management.
    - **[Getting started with KSP](https://kotlinlang.org/docs/ksp-quickstart.html)** — Guide for integrating KSP-based annotation processors into your project and creating custom annotation processors via Gradle configuration.

    - **[Migrate from kapt to KSP](https://kotlinlang.org/docs/ksp-kapt-migration.html)** — Explains how to migrate annotation processors from kapt to KSP, contrasting kapt's slow Java stub translation with KSP's direct Kotlin source analysis.
    - **[KSP examples](https://kotlinlang.org/docs/ksp-examples.html)** — Provides practical code examples for common KSP tasks including accessing member functions, checking local declarations, and resolving type aliases.
    - **[How KSP models Kotlin code](https://kotlinlang.org/docs/ksp-additional-details.html)** — Describes KSP's API for modeling Kotlin code, explaining type resolution mechanisms and the distinction between KSTypeReference and KSType.
    - **[Java annotation processing to KSP reference](https://kotlinlang.org/docs/ksp-reference.html)** — Comprehensive mapping between Java annotation processing API constructs and their KSP equivalents to aid migration.
    - **[Incremental processing](https://kotlinlang.org/docs/ksp-incremental.html)** — Explains KSP's incremental processing that reprocesses only files with changed dependencies to reduce compilation time, enabled by default.
    - **[Multiple-round processing](https://kotlinlang.org/docs/ksp-multi-round.html)** — Describes KSP's multi-round processing where processors can return deferred symbols to be reprocessed in subsequent rounds.
    - **[KSP with Kotlin Multiplatform](https://kotlinlang.org/docs/ksp-multiplatform.html)** — Guides configuring KSP for multiplatform projects using target-specific configurations like `add(ksp<Target>)`.
